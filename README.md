# 资源导航 · 说明

一个纯静态的常用网站导航页。没有后端、没有数据库，双击就能看。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构，基本不用改 |
| `style.css` | 全部样式（新拟物风格） |
| `data.js` | **所有站点都在这里**，加站点改这个 |
| `app.js` | 渲染、搜索、视图切换的逻辑 |
| `me.html` | 旧的个人主页，留作备份 |

## 加一个站点

打开 `data.js`，在对应分类里加一行：

```js
{ name: "站点名", url: "https://example.com", desc: "一句话说明" },
```

保存、刷新，就出现了。

## 加一个分类

在 `SITE_DATA` 数组里加一个对象：

```js
{
  cat: "新分类",
  items: [
    { name: "…", url: "…", desc: "…" },
  ],
},
```

再去 `app.js` 顶部的 `CAT_COLORS` 里给它配一个颜色。

## 改主题色

`style.css` 顶部有一组变量：

```css
--violet: #6d5dfc;   /* 主色 */
--bg:     #e0e5ec;   /* 底色 */
```

改 `--violet` 会同时影响搜索框聚焦、按钮文字和 AI 分类的圆点。

## 视觉规则（新拟物）

这套设计的核心是「一束左上方的光」：

- 元素和背景同色，靠**双阴影**造体积
- 右下阴影 = 暗，左上阴影 = 亮
- **凸**（外阴影）= 可点击；**凹**（内阴影）= 内容区或被按下
- 颜色只出现在圆点和图标字母上，大面积保持无彩

改样式时如果阴影方向反了，整个页面会显得「塌陷」，务必保持左上光源。

## 视图与交互

**两级结构**：首页是六个分类大块，点进去才展开该类站点，同一页面内切换，不刷新。

- 地址栏会带 hash（如 `#AI%20%E5%B7%A5%E5%85%B7`），浏览器后退键可用
- 分类页底部有「上一组 / 下一组」，可以连续翻
- 左上角「← 全部」或点 Logo 回到首页
- 搜索框搜全部站点，支持俗称（`b站`、`cnki`、`gh`、`163` 等），按 `/` 聚焦，`Esc` 清空或返回
- 卡片悬停浮起、按下内凹

## 别名怎么加

`data.js` 里每个条目可以带 `alias`：

```js
{ name: "哔哩哔哩", url: "…", desc: "…", alias: ["b站", "bilibili"] },
```

搜索结果会匹配 `alias`，方便记不住全名时直接搜。

## 背景粒子

`particles.js` 是**手写的 canvas 粒子，零依赖**（早期试过 tsParticles，后来为了让「悬停卡片就散开」可控，换成了自绘）。

### 行为

| 场景 | 粒子反应 |
|---|---|
| 平时 | 随机游走，互相之间有短程斥力，**不会粘成一团** |
| 出界 | 从另一侧绕回来（不是反弹），所以不会堆在角落 |
| 鼠标靠近 | 被拉向一个半径 88px 的环，绕光标缓慢旋转，不会被吸成一个点 |
| 靠近光标的粒子 | 变大变亮（光晕），不画连线 |
| 鼠标停在卡片/按钮上 | 快速推开，散开一圈 |
| 鼠标离开窗口 / 切到别的窗口 | 整片向外爆散一次，然后继续自由游动 |
| 点击卡片 | 再爆散一次 |

> 早期版本做过「吸附连线」，视觉上像蜘蛛网，已改为无连线 + 光环。

### 可调参数

都在 `particles.js` 顶部：

```js
const LINK_DIST = 95;     // 粒子间连线距离
const LINK_ALPHA = 0.10;  // 粒子间连线透明度（不想看到连线就改 0）
const MOUSE_RADIUS = 210; // 鼠标影响半径
const RING_R = 88;        // 鼠标周围环的半径
const SPRING = 0.0022;    // 拉回环上的力度（越小吸得越轻）
const SWIRL = 0.014;      // 绕圈速度（越小转得越慢）
const REPULSE = 2.4;      // 悬停卡片时推开力度
const WANDER = 0.1;       // 随机游走
const DAMPING = 0.985;    // 阻尼
const MAX_SPEED = 1.8;    // 常态限速
const BURST_SPEED = 7;    // 爆散瞬间限速
const GAP = 46;           // 粒子间最小间距
// 密度：density() 里 (W*H)/6200，上限 240
```

### 已做的限制

- 系统开启「减少动态效果」→ 不启动
- 屏幕 ≤700px → 粒子密度减半
- 画布 `pointer-events: none`，不挡点击
- 速度上限 2.2，爆散后不会飞出天际

### 想让粒子盖在卡片上面

默认图层在内容下面（`z-index: 0`）。想让它浮在卡片之上，改 `style.css`：

```css
#tsparticles { z-index: 5; }   /* 原来是 0 */
```

但那样文字上会飘粒子，自己掂量。


## 明暗模式

右上角的月亮/太阳按钮切换。默认跟随系统，点过之后记住你的选择（`localStorage` 的 `nav-theme`）。

暗色不是简单反色——新拟物靠阴影活着，所以暗色下三件事都要重配：

| 变量 | 亮色 | 暗色 |
|---|---|---|
| `--bg` | `#e0e5ec` | `#2e3238` |
| `--dark`（右下阴影） | `#c2c7cf` | `#1e2126` |
| `--light`（左上高光） | `#ffffff` | `#3d434e` |

光源方向不变（左上），只是把「亮背景上的浅阴影」换成「暗背景上的深阴影」。
如果只改背景色不改阴影，整页会变成一团没有体积的灰。

粒子层也跟着换配色：`particles.js` 顶部有 `PALETTE.light` 和 `PALETTE.dark`，切换时通过 `themechange` 事件同步。
